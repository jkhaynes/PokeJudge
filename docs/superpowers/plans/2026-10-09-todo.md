**Quota:** one `evaluate --repeat 3` uses roughly 400–450 of Gemini's 500 free chat calls a day, so it's **one full run
per day**. Don't start a second full run the same day; it fails with `429 RESOURCE_EXHAUSTED` after a few scenarios,
as the attempt on 2026-10-08 did. The quota does **not** reset at 00:00 UTC, even though the 429 says "retry in"
a time that counts down to it: a run at 03:01 UTC on 2026-10-09 failed on all 60 scenario-runs. It probably resets at
midnight Pacific (07:00 UTC, 3 am Eastern), like the embedding quota; if a run fails at once after that, the window is
rolling and clears about 24 hours after the previous run.
