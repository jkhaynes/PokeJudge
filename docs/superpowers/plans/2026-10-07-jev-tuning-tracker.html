How each iteration is measured

  1. The 20 scenario turn-1 descriptions, each sent 3 times through search --top 5 --rerank jev, reading every needed section's rank from the 30 printed Jev scores. That's 60 Jev requests and 60 embeddings, and no Gemini chat calls.
  2. eval (29 search-only questions), 1 run: 29 more of each.
  3. From v1 on, PokeJudge retries temporary Jev failures itself, and each retry counts under Jev retries. A search that still fails is counted under Jev failures and run again, so the ranks stay complete. (For v0, the measuring script retried a 503 itself.)

These are turn-1 checks only. Later turns depend on the model's questions, so only a full evaluate run measures them. That's saved for the final candidate.

To add an iteration: add an entry to ITERATIONS, add its ranks under the same id in SCENARIOS and SEARCH, and add its notes to the top of NOTES.
